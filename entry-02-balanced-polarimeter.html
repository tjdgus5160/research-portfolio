PBS의 두 출력을 일치한 광다이오드 쌍으로 받아, 차분으로 패러데이 회전 신호를, 합으로 광 세기를 읽는 균형 편광계. YAML 사양 기반 FreeCAD 파라메트릭 빌드로 설계하고 형상 검사를 통과했다.

PBS의 두 출력을 일치한(matched) 광다이오드 쌍으로 받아들인다. 두 광전류의 차는 패러데이 회전 신호를 운반하고, 합은 광 세기를 운반한다. 같은 방향으로 들어오는 common-mode 잡음은 차분에서 상쇄되므로, 광 세기 변동에 둔감한 회전각 신호를 얻을 수 있다.

S = (I₁ − I₂) / (I₁ + I₂) ≈ 2·θ_F

I₁
투과 포트 광전류
I₂
반사 포트 광전류
θ_F
패러데이 회전각

= 세기 변동에 둔감한 회전각 신호

CALCULATED

소각 근사는 θ_F ≪ 1 rad 범위에서 성립한다.

설계 원칙

모델은 도면이 아니라 파라미터로 기술된다. housing.length를 바꾸면 모든 종속 plane, pocket, bore가 다시 유도되고, 전체 조립체가 다시 빌드되어 다시 검증된다.

uv run cadctl build configs/opm_sensor.yaml --overwrite

파라메트릭성은 주장하지 않고 테스트로 증명한다. 통합 테스트가 런타임에 reference config로부터 더 짧은 envelope을 생성하고, 그로부터 전체 모델을 다시 빌드한다(test_a_resized_envelope_rebuilds_the_whole_model).
